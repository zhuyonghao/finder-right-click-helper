# 右键助手 v1.0.6

本次更新优化 macOS 原生界面与新建文件对话框。

## 更新内容

- 主窗口采用系统侧栏、统一工具栏、紧凑模板表格和分组设置，跟随系统深浅色外观。
- 菜单预览支持收起与恢复；模板支持双击编辑、搜索和右键操作。
- 增加添加模板（⌘N）、导入模板（⌘O）与搜索模板（⌘F）快捷键。
- 新建文件改用紧凑原生面板，分开显示文件名、扩展名和保存位置。
- 自动选中文件名，支持回车创建与 Esc 取消；空名称禁用创建，非法名称在面板内提示。
- 保留同名文件自动编号；手动输入模板扩展名时，界面避免重复显示扩展名。

## 下载与安装

下载 `FinderHelper-macOS-arm64-v1.0.6.zip`，解压后将「右键助手.app」放入「应用程序」，打开应用并在系统设置中启用 Finder 扩展。

- 系统要求：macOS 14 及以上。
- 架构：Apple Silicon（arm64）。
- 应用及 Finder 扩展版本：1.0.6，构建号 7。
- 签名：本地 ad-hoc 签名，未进行 Developer ID 签名与公证。
- 同时提供 `.zip.sha256` 文件，用于校验下载包完整性。
